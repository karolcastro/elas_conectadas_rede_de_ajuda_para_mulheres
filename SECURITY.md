# Política de segurança — Elas Conectadas

## Escopo

Esta política cobre o código e as configurações deste repositório. O servidor atual utiliza transporte MCP stdio. Uma futura implantação remota exige revisão de arquitetura, autenticação, autorização, proteção de transporte e teste de segurança antes de receber dados reais.

## Como reportar uma vulnerabilidade

- Não publique senhas, tokens, chaves, dados pessoais ou detalhes exploráveis em issues públicas.
- Se o recurso estiver habilitado no GitHub, use **Security → Advisories → Report a vulnerability** para enviar um relato privado.
- Inclua o caminho/versão afetado, impacto observado e passos mínimos de reprodução usando dados fictícios.
- Não envie relatos reais de violência, dados de saúde ou informações identificáveis de usuárias.

## Regras para testes

- Testar apenas este repositório e ambientes sob autorização explícita.
- Usar dados fictícios; não testar sistemas governamentais, ONGs ou serviços de terceiros sem autorização.
- Não executar testes destrutivos, negação de serviço ou extração de dados.
- Ao encontrar credencial exposta, interromper o teste, não reutilizar a credencial e solicitar rotação ao responsável.

## Proteção de dados

O projeto deve seguir minimização de dados, finalidade, transparência e retenção mínima. Não solicitar credenciais gov.br, CPF, relatos detalhados ou localização precisa sem necessidade e consentimento. Nunca publicar endereços sigilosos de abrigos ou dados de pessoas atendidas.
